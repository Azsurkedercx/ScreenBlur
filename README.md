# ScreenBlur

Windows 上的半透明磨砂窗口，用来遮住下层显示内容。

## 特性
- 两种模糊方式：高斯模糊（CPU 截屏计算）/ 彩色磨砂（Windows Acrylic）
- 无边框、可拖动、可缩放
- 鼠标穿透（锁定模式）
- 多次运行可实现多遮罩窗口
- 点击托盘可隐藏/显示窗口
- 支持截图/录屏（可选）
- 配置保存到同目录 ini

## 编译
需要 [w64devkit](https://github.com/skeeto/w64devkit)，把 `bin` 加入 PATH 后双击 `build.bat`。

## 使用
见程序内“软件说明”。
